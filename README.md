# Гарантовано

**Опиши звичайними словами, що тобі потрібно. Ми покажемо найближчі заклади, де це безкоштовно за Програмою медичних гарантій, і що робити, якщо просять гроші.**

Open Data Hackathon, 16.11.2026 · дані НСЗУ з data.gov.ua · Python + Streamlit.

## Проблема
Багато послуг за ПМГ безкоштовні: ведення вагітності, пологи, мамографія, лікування інсульту й інфаркту, зубопротезування для ветеранів. Люди не знають, що саме безкоштовно і в якому закладі є договір з НСЗУ, тому платять або отримують відмову. Мапа НСЗУ вимагає знати службові назви пакетів і не пояснює прав пацієнта. Деталі: `docs/IDEA.md`, `docs/research/`.

## Демо-сценарій
«Я вагітна, 10 тижнів, живу на Оболоні. Де стати на облік і народжувати безкоштовно?»
→ пакети 35 + 7 (+8 неонатальна допомога) → найближчі заклади на мапі → картка прав і гаряча лінія НСЗУ 16-77.

## Запуск
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
cp .streamlit/secrets.toml.example .streamlit/secrets.toml   # вставити ANTHROPIC_API_KEY
pytest -q
streamlit run app.py
```
Оновити дані НСЗУ: `python scripts/ingest.py`.

## Як працюємо (перевірка обов'язкова)
1. Береш свою задачу → гілка `feat-<issue>-<name>` → маленькі коміти.
2. PR у `main` за шаблоном. CI запускає тести, сканер ключів і перевірку «тільки Python».
3. Назар пише в PR `@codex review`. Codex перевіряє за правилами `AGENTS.md` → «Review guidelines». Усі P0/P1 виправляються.
4. Мерджить тільки Назар. Прямий пуш у `main` заборонений.
